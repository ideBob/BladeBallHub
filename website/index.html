Engineering Philosophy

Built for maintainability and resilience in executor environments.

Modular

Features are separated into manageable systems with a centralized State and Config.

Configurable

Parry distance, reaction time, prediction strength, and dash parameters are adjustable.

Responsive

WindUI window designed for desktop and mobile executors.

Defensive

Feature isolation via pcall — one failure does not bring down the entire interface.
